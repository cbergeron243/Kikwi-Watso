KikwiNok — Seasonal Azimuth Explorer (Offline)
Version: v0.1
Author: Cam Bergeron (Ndakinna Creations)
Purpose: Fast, repeatable screening for possible solar/lunar alignment directions at a site.

What KikwiNok does

KikwiNok calculates azimuth targets (degrees from North) across a year range for:

Seasonal SUNSET and/or SUNRISE markers (Solstices, Equinoxes, Cross-quarters)

Optional Lunar standstill reference rails (major/minor, N/S)

It saves:

a PNG chart (visual)

a CSV dataset (all computed values)

What it is / what it isn’t

✅ A triage/screening tool to guide field checks and prioritize return visits

❌ Not proof of intentional design, dating, or cultural attribution

✅ Best used with field measurement, horizon notes, and context

Why there is no Longitude field

For azimuth targets at rise/set, longitude is not required.
Longitude is needed for event times (clock time) and time-specific sky positions.

How to run (30 seconds)

Double-click KikwiNok.exe

Enter Site name, Latitude, Elevation, Start year, End year

Choose options (Lunar rails / Sunset / Sunrise)

Click Run KikwiNok

Output files

Saved to your selected output folder:

…_kikwi.png (chart)

…_kikwi.csv (table)

Field workflow tip

Measure a site sightline azimuth (phone compass is fine for screening), then compare to the chart’s target families. If it’s close, it may be worth deeper measurement and follow-up.
